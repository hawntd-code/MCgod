# Plugins de generación

Copias sin modificar de plugins de [MCreator](https://github.com/MCreator/MCreator), tomadas de su repositorio en el commit `c3d9446` (15 de noviembre de 2026). MCgod los lee tal cual: así genera el mismo código que MCreator y puede traer versiones nuevas de Minecraft copiando plugins nuevos.

| Carpeta | Contenido |
|---|---|
| `generator-1.21.1/` | Generadores NeoForge 1.21.1 (`neoforge-1.21.1`), Data Pack y Resource Pack de Minecraft 1.21.1: `generator.yaml`, definiciones de cada tipo de elemento, plantillas FreeMarker, tablas de nombres (`mappings`) y la base de proyecto (`workspacebase`) |

Licencia: GPL-3.0, de Pylo y los colaboradores de MCreator. Las plantillas (`*.ftl`) además tienen el permiso adicional que describe su propio encabezado. Ver [NOTICE.md](../NOTICE.md).

Para actualizar una copia, reemplaza la carpeta completa con la del repositorio de MCreator y anota aquí el commit.
